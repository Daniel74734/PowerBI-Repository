**Superstore Sales Report**

Designed and developed an interactive two-page Superstore Sales 
Dashboard that visualizes key sales metrics including regional 
performance, product categories, customer segments, shipping 
modes, and year-on-year sales trends.

**Tools Used**
- Microsoft Power BI
- DAX
