**Hospital Patient Analytics Dashboard**

  Designed and developed an interactive Hospital Patient Analytics 
Dashboard that visualizes key healthcare metrics including patient 
demographics, diagnoses, treatment outcomes, doctor performance, 
and financial payments.

Tools Used
- Microsoft Power BI
- DAX
