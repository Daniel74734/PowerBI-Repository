HR Analytics Dashboard

Designed and developed an interactive two-page HR Analytics 
Dashboard that visualizes key workforce metrics including employee 
demographics, performance scores, training costs, and engagement 
levels across six departments.

Tools Used
- Microsoft Power BI
- DAX
